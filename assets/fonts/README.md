# 🛒 PDV Online

Sistema de Ponto de Venda (PDV) desenvolvido com HTML, CSS e JavaScript puro para praticar conceitos de desenvolvimento Front-End, manipulação do DOM e lógica de programação.

```text
PDV ONLINE
├── Produtos
│   ├── Pesquisa
│   ├── Cards de Produtos
│   └── Scroll de Navegação
│
├── Checkout
│   ├── Quantidade
│   ├── Número de Itens
│   └── Total da Compra
│
└── Ações
    ├── Remover Itens
    └── Finalizar Compra
```

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
